# Xerilium AI plugins

Marketplace for Xerilium plugins for AI coding agents.

## Catalyst

Spec-driven AI development workflows with human checkpoints. See the [Catalyst docs](https://github.com/xerilium/catalyst#readme).

### Claude Code

```text
/plugin marketplace add xerilium/ai-plugins
/plugin install catalyst@xerilium
```

### Other agents

Install the `@xerilium/catalyst` package and load the Agent Plugins package it ships. See the [install steps](https://github.com/xerilium/catalyst#install).

## About this repository

`.claude-plugin/marketplace.json` is generated and published by the Catalyst release workflow. Don't edit it by hand.
